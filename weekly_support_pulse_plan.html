Slide 4 — Next Steps to Make This Real

Three actions to operationalize this workflow starting next Monday

1
Confirm Cloud List & Date Range for First Pull
Run this weekly against OrgCS Salesforce data once you confirm which clouds to include and the start date for the first pull. The initial run establishes the 4-week baseline needed for rolling trend comparisons starting in Week 5.
2
Wire the Sev 1 Section to the Guide & Architect Skill
Slide 2 can run directly on the existing Guide & Architect Recommendation skill already in place — it classifies Signature-tier cases as Guide or Architect engagements and automatically surfaces the account's CSM for Architect recs. No new logic needed; just invoke the skill against this week's Sev 1 list.
3
Build a Running CSM Alignment Tracker in Slack
For Slide 3, a persistent Slack canvas will be created so alignment status (Aligned / Pending / No Response) survives week-to-week without re-querying the full table. Each Monday the canvas is patched with the new Top 10 and any status changes — giving leadership a live view with no manual upkeep.
